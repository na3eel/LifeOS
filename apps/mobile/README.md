# LifeOS Mobile

Expo Router + React Native + TypeScript.

## Requirements
- Node.js LTS compatible with Expo SDK 54
- npm
- Android Studio / Android SDK for Android local builds
- Xcode on macOS for iOS local builds

## Run
```bash
cd apps/mobile
npm install
npx expo start
```

## Current routes
- /(tabs) — Today dashboard
- /(tabs)/life-areas — Life areas
- /(tabs)/calendar — Calendar placeholder
- /(tabs)/insights — Insights placeholder
- /(tabs)/coach — AI Coach placeholder

Theme follows system light/dark mode. These screens currently use sample presentation data; API and offline storage integration are not complete.
